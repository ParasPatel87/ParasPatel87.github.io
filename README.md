# Paras R. Patel — scientific profile

## Open
Open index.html in a browser. new.html opens the same home page.
Every navigation item opens its own page:
- index.html / new.html: home
- about.html: profile
- research.html: research themes and computational toolkit
- publications.html: journal articles and preprint; search, year filters, citation copying
- experience.html: education, teaching, recognition, and research visits
- conferences.html: presentations, schools, and professional development
- contact.html: email and academic profiles

No installation is required. For an HTTP preview, run Start-Preview.ps1 and open http://localhost:4173.

## Maintain
Edit the corresponding HTML page for profile text. Edit publications.js for the interactive publication list and keep the static list in publications.html consistent. styles.css and script.js are shared.
Use real profile URLs when adding academic or code profiles. Contact uses email links.
The lattice illustration is a schematic rather than a calculated structure.
